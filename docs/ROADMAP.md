# План

Статусы: ✅ готово · 🔜 следующий шаг · ⏳ ждёт решения или данных · 💡 идея

## Сделано

- ✅ Ядро хаба: события МойСклад (вебхуки + опрос), очередь, один запуск на ключ, повторы с алертом,
  dry-run, SQLite / PostgreSQL, роли api / worker / scheduler.
- ✅ Заказы, отгрузки, контрагенты: статусы и доп. поля по именам (все типы, включая справочники), REST, CLI.
- ✅ `daily_upd` — УПД за день в 17:00 на почту: отгруженные, по заказам, ИП и ООО.
  Пробный прогон на живом аккаунте 26.10.2026: отбор верный, у 3 контрагентов нет e-mail.
- ✅ Лимит запросов МойСклад по графику веса запроса (сейчас 15 за 3 с, с 01.12.2026 — 11).
- ✅ Бот очереди заказов (`hub/orders`): свой токен, только закрытый чат, заказ покупателя
  после «да». Справочный бот по-прежнему только читает. `HUB_DRY_RUN=1` показывает черновик
  и не создаёт документ.
- ✅ Telegram-бот и `POST /api/ask`: вопросы по МойСклад обычным языком, только чтение —
  остатки, продажи без перемещений, заказ на N дней (сиропы, сырьё), неоплаченные
  отгрузки с просрочкой, цены поставщика, техкарты, оборот по месяцам.

## Остатки сырья по чаю в Telegram

Склад «К 49 (СКЛАД ТОЛЬКО СЫРЬЯ!)». Позиции: матча (Токусен, Удзи, Голубая, кулинарная),
ходзича пудровая, ходзича листовая.

1. 🔜 **Отчёт и пороги без LLM** — автоматизация `stock_report`:
   - утром (09:00?) таблица остатков в Telegram: остаток, резерв, себестоимость;
   - каждые 30 мин сверка с порогами из `config.yaml`; предупреждение один раз при падении
     ниже порога и один раз при пополнении;
   - отдельно — отрицательные остатки (сейчас у кулинарной матчи −0,5 кг) как признак
     непроведённой приёмки.
2. ✅ **Telegram-бот с LLM-интерфейсом** (`hub/bot`); дальше по плану:
   - ✅ бот в том же контейнере, long polling, белый список чатов, история на чат;
   - ✅ Claude API (Python SDK, свой цикл инструментов), `claude-opus-5-5`, effort из
     `HUB_BOT_EFFORT` (по умолчанию medium), `fallbacks: "default"`, кеш system и tools;
   - 🔜 инструменты порогов: `low_stock`, `get_thresholds`, `set_threshold`;
   - 💡 запись с подтверждением: заказ поставщику черновиком по результату `reorder`;
   - ✅ токен МойСклад модели не виден, в МойСклад бот не пишет; пороги и любые действия
     в будущем — только после кнопки «Подтвердить»;
   - ориентир по цене: ~$0,02–0,04 за вопрос на Opus 5.5; вариант дешевле — `claude-haiku-5-5`,
     сравнить на реальных вопросах.

Нужно от владельца: `ANTHROPIC_API_KEY` и токен Telegram-бота в переменных Dockhost, id чата,
пороги по позициям, время утреннего отчёта, отслеживать ли наклейки.
