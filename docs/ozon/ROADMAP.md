# Дорожная карта Ozon

Статусы: сделано в этом срезе, ждёт владельца, не начинать без отдельного решения.

## Сделано

- Модуль `ozon_fbs_import` выключен. Ручная команда читает один кабинет и пишет снимок в `/data/hub.sqlite3`.
- Ключ операции, уникальные ограничения, WAL, транзакция, копия SQLite без перезаписи.
- Нагрузка 100 000 ключей и восстановление после `SIGKILL` на SQLite.
- Контракт списка FBS v4 зафиксирован по источникам от 26.11.2026. Официальный HTML в этот день не открылся.

## Ждёт владельца, без этого в МойСклад не пишем

- Организация, контрагент, тип договора, проект, канал, склады по кабинету.
- Подтверждение имён статусов из `STATUS_MAP.md`.
- Нужен ли резерв уже при создании заказа или заказ остаётся непроведённым.
- Часы, которые прибавляются к дате отгрузки, и округление копеек.
- Что считать самовыкупом.

## Следующий срез кода, после ответов

1. Заказ FBS с `externalCode` `ozon:{кабинет}:{отправление}`. Перед созданием искать документ. Не удалять и не трогать чужие.
2. Статус заказа по подтверждённой карте. Не использовать статус маршрутного листа.
3. Отмена до отгрузки: снять проведение и резерв. Если отгрузка есть, остановиться и записать журнал.
4. Одна отгрузка на отправление.
5. Возврат только с основанием-отгрузкой. Списание потери с обязательным комментарием. Обратно в доступный остаток не перемещать.

Push и периодическая сверка подключаются после того, как владелец отдельно согласится менять подписки. Пока подписки не трогаем, сверка может идти тем же чтением списка.
