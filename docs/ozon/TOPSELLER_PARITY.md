# Сверка с TopSeller. 26.11.2026

Справка TopSeller прочитана в этот день: настройки FBS и комиссии, статусы, склады, возвраты, FBO. Коды Seller API в справке не опубликованы, поэтому русские имена статусов в `STATUS_MAP.md` остаются предложением.

TopSeller на проде не выключается. Хаб не редактирует его документы.

## Что TopSeller делает и что берём

| Поведение TopSeller | Решение хаба |
|---|---|
| Заказ FBS, статус, резерв, отгрузка, отмена, возврат | следующий срез после карты кабинета. Сейчас только снимок в базе |
| Обязательный комментарий на потерю и утилизацию | списание с непустым `description`. Не возвращать в доступный остаток |
| Разрез по кабинету, организации, проекту, договору | ключ начинается с кабинета. Организация и договор — блокер владельца |
| FBO: продажи и виртуальный склад | схема `fbo` зарезервирована в ключе. Метод списка не зафиксирован и не вызывается |
| Остаток МойСклад → Ozon FBS | отдельное согласование, выключено |
| Нумерация номером отправления | так и будет, когда появятся документы |
| Цена из Ozon, округление копеек | цена строки хранится строкой API. Проведение цены ещё не делается |
| Карта складов и часов к дате отгрузки | ждёт решения владельца |
| Ручные правки заказа не затирать | чужой `description` не заменяется |
| Самовыкупы | не реализовано. Первые 8 цифр до дефиса и нулевые цены не угадываем |
| Фильтр склада | не включён: список идёт без `warehouse_id` |
| Уведомления | не делаем, каналы хаба этот модуль не вызывает |

## Где сознательно расходимся

| TopSeller | Хаб |
|---|---|
| Удаляет документы при отмене до отгрузки | не удаляет. Снимает проведение и резерв, если отгрузки ещё нет |
| На «Доставлен» создаёт входящий платёж | не создаёт. Доставка не равна выплате |
| Одной кнопкой перемещает весь склад возврата | не делает. Каждое движение — отдельная операция с ключом |
| Может вернуть потерю в продажу | запрещено |
| Пишет в те же документы, что уже ведёт | префикс `ozon:{кабинет}:{отправление}`, чужие документы не трогаем |

## Возвраты в интерфейсе TopSeller

Подписи, которые видны в справке, не коды API: «Возвращен», «Возвращен для перепродажи», «Утилизирован», «Возвращен после отмены в процессе», «Возвращен селлеру», состояния документа «Озон.Возврат.Можно забирать все» и «Завершено».

Метод списка возвратов на 26.11.2026 не зафиксирован и не вызывается. Пока нет метода, эти подписи нельзя сопоставить с полем ответа.
