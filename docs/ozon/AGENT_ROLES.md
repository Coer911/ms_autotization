# Роли агентов

Общие правила хаба остаются в `CLAUDE.md` и `AGENTS.md`. Этот файл задаёт границы работы по Ozon.

Срез 26.11.2026 собран последовательно в одной ветке. Общие файлы (`hub/storage/__init__.py`, `hub/__main__.py`, `hub/settings.py`, `config.yaml`) нельзя править параллельно из разных worktree. Следующий срез можно делить только после того, как контракт в `docs/ozon/` согласован и чужие файлы не пересекаются.

В `main` не мержить. Продовые автоматизации, подписки Push и TopSeller не менять. Токен администратора МойСклад не использовать. Секреты не печатать и не коммитить.

## 00. Архитектор

Файлы: `docs/ozon/`, `AGENTS.md`, короткие ссылки в `CLAUDE.md`, `README.md`, `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`.

Вход: решение по SQLite и запрет на новые сервисы. Выход: контракт, который остальные роли не расширяют по памяти.

Приёмка: поведение `logistics_sheet` и остальных текущих автоматизаций не изменено. Новые модули выключены.

## 01. Клиент Ozon

Файлы: `hub/ozon/client.py`, `hub/ozon/redact.py`, `hub/ozon/statuses.py`, `hub/ozon/ids.py`.

Вход: `API.md`. Выход: один вызов списка FBS v4 и снимок без персональных данных.

Приёмка: конверт v3 отвергается, редирект не следует, ключ не попадает в текст ошибки.

## 02. Сопоставление

Файлы: `hub/ozon/match.py`. `hub/moysklad/client.py` в этом срезе не менять.

Вход: `offer_id`. Выход: `matched`, `unmatched`, `ambiguous`, `skipped`, `no_catalog`.

Приёмка: два товара или товар и модификация с одним артикулом дают `ambiguous`. Небезопасный артикул не уходит в фильтр.

## 03. Хранилище

Файлы: `hub/storage/ozon.py`, `hub/storage/backup.py`, регистрация таблиц в `hub/storage/__init__.py`.

Вход: снимок. Выход: три таблицы, WAL уже у ядра, команда копии SQLite.

Приёмка: повтор не создаёт вторую операцию. Копия не затирает существующий файл. PostgreSQL-совместимость ядра сохранена.

## 04. Импорт FBS

Файлы: `hub/ozon/fbs_import.py`, `hub/automations/ozon_fbs_import.py`, `config.yaml`, `.env.example`, команды в `hub/__main__.py`.

Вход: клиент, хранилище, необязательный токен МойСклад. Выход: статистика. Расписание выключено.

Приёмка: нет вызовов `set_state` и `set_fields`. Без ключей включённая автоматизация не стартует.

## 05. FBO

В этом срезе только текст в `docs/ozon/`. Кода списка FBO нет, пока не зафиксировано тело `POST /v3/posting/fbo/list`.

## 06. Возвраты

В этом срезе только правила в `ACCOUNTING_RULES.md`. Метод возвратов не вызывается.

## 07. Секреты и персональные данные

Смотрит diff. Нельзя: сырой JSON отправления, покупатель, адрес, телефон, финансы, ключ в логе, приём push, смена подписок, админский токен.

## 08. Тесты

Файлы: `tests/test_ozon_fbs.py`, `tests/test_ozon_load.py`.

Приёмка: `python3 -m pytest -q` и `ruff check .`. Нагрузка 100 000 ключей и убийство процесса проверяются на SQLite. Функциональные тесты написаны на общем SQLAlchemy и в CI идут и на PostgreSQL.
