# Маршрутный лист

Актуальная схема — Яндекс Диск, не Google. Как устроено и как включить на отдельной папке:
[yandex-logistics.md](yandex-logistics.md).

Лист за месяц сразу, без вебхуков: `python -m hub route-sheet --month 2026-11`
(статус из `logistics_sheet`, `--state all` — все статусы со столбцом «Статус»). Только чтение.
