# Печатные формы МойСклад

Шаблоны, которые загружаются в МойСклад руками: через JSON API шаблоны можно только
читать, загрузить или изменить нельзя (`docs/moysklad-api/workbook/_workbook_print_templates.md`).

## Стикер курьера 120×75 — заказ покупателя

`courier_label_120x75.xls` — термостикер на заказ: всё, что нужно курьеру.

| На стикере | Откуда |
|---|---|
| ЗАКАЗ № … от дд.мм.гггг | номер и дата заказа |
| Доставка | доп. поле заказа «Тип доставки» |
| Получатель | покупатель (контрагент заказа) |
| Телефон | доп. поле заказа «Номер телефона», если пусто — телефон из карточки покупателя |
| Адрес | адрес доставки заказа |
| Комментарий | комментарий заказа (до 3 строк, длиннее обрежется) |
| Сумма / Оплата | сумма заказа / доп. поле «Оплата» |
| Мест: ____ | вписать от руки при сборке |
| Позиций | число позиций в заказе |
| Отправитель | ваша организация из заказа и её телефон |

Пустое поле печатается пустой строкой. Имена доп. полей зашиты в `courier_label.py`
(`ATTR_*`) и должны совпадать с МойСклад буква в букву.

### Загрузить в МойСклад

1. Откройте любой заказ покупателя → **Печать** → **Настроить…** и добавьте свой шаблон
   файлом `courier_label_120x75.xls`. Имя задайте, например, «Стикер курьера 120х75».
2. Напечатайте один заказ в PDF и проверьте размер страницы. Если он 120×75, печатайте на термопринтер
   в масштабе 100 % («Фактический размер»), бумага в драйвере — 120×75.
3. Если PDF вышел на A4: размер стикера в `.xls` записан в настройках принтера (запись PLS),
   а их понимают не все конвертеры. Тогда нужно взять настройки страницы из шаблона, который
   у вас уже печатается на этот принтер (например, `etiketka_75x120`).

После загрузки хаб видит шаблон по имени: `python -m hub templates orders`,
`GET /api/orders/{ref}/print?template=Стикер курьера 120х75`.

### Поменять стикер

Правьте `courier_label.py`: поля и надписи, сетку `COLS_MM` / `ROWS_MM` (в сумме 114 × 71 мм —
стикер минус поля), шрифты в `build()`. Пересобрать:

```bash
pip install xlwt
python print_templates/courier_label.py
```

Затем загрузите новый файл в МойСклад вместо старого.

Выражения `${…}` — разметка jXLS, как в стандартных шаблонах МойСклад
(`GET /download-template/order.xls`, `invoice-stamp-sign.xls`). В заказе покупателя
`o.sourceAgentRequisite` — покупатель, `o.targetAgentRequisite` — ваша организация.
Доп. поля — `formatter.findAttribute(o, "Имя").valueString` (строка) или `.entityValue.name`
(справочник), адрес доставки — `o.addressFull`, комментарий — `o.description`
(справка МойСклад «Основные формулы вывода данных из документа»).
